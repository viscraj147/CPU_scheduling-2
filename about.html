About the Project

Academic engineering project exploring the computational foundation of CPU scheduling algorithms and their underlying fundamental Data Structures.

🎯 Project Objective & Problem Statement

Problem Statement: In undergraduate Computer Science curricula, CPU scheduling algorithms are frequently taught as theoretical scheduling formulas without demonstrating the concrete memory structures, array indexing, and queue pointer manipulations required to implement them on real hardware.

Objective: To develop an interactive, multi-page educational web simulation platform that bridges Operating Systems concepts and Data Structures by demonstrating how Contiguous Arrays, FIFO Queues, Circular Ring Buffers, and Min-Heaps manage processes during scheduling execution in real time.

✨ Key Educational Features

  • Deterministic Simulation Engine: Step-based scheduler producing mathematically precise snapshots with instant backward step rollback.
  • Dual OS & DS Visualizations: Real-time process array memory (p[N]), FIFO ready queues, and Round Robin circular ring buffers.
  • Dynamic Starvation & Aging: Demonstrates priority promotion algorithms to prevent indefinite postponement.
  • Interactive Data Structure Lab: 6 dedicated interactive modules covering Arrays, Queues, Circular Queues, Min-Heaps, BSTs, and LIFO Call Stacks.
  • Persistent History & Comparison: Browser-local run storage, replay capabilities, side-by-side run comparisons, and CSV reports.

📚 Learning Outcomes

  • Understand the exact mapping between Process IDs and array indices in memory.
  • Appreciate how Circular Queues avoid O(N) memory shifts using modulo arithmetic.
  • Evaluate trade-offs between preemption responsiveness and context switching overhead.
  • Gain confidence in Data Structures & Operating Systems viva voce examinations.
