⚡ Supported CPU Scheduling Algorithms

Compare All Details
FCFS Non-Preemptive
DS: Linear FIFO Queue

Dispatches processes in chronological order of arrival. Simple and overhead-free, but vulnerable to the convoy effect.

SJF Non-Preemptive Non-Preemptive
DS: Min-Heap / Sorted Array

Selects the arrived job with the shortest CPU burst time. Minimizes average waiting time for simultaneous workloads.

SRTF Preemptive
DS: Dynamic Min-Heap (Rem. Time)

Preemptive variant of SJF. Preempts the current job whenever a newly arrived process needs less remaining execution time.

Round Robin Preemptive (Time Slice)
DS: Circular Ring Buffer (Queue)

Assigns a fixed time quantum to each job in cyclic order. Unfinished jobs wrap around to the rear of the ready queue.

Priority Non-Preemptive Non-Preemptive
DS: Priority Queue / Linear Scan

Dispatches the highest-priority arrived job. Runs to completion without interruption once assigned to the CPU.

Priority Preemptive Preemptive
DS: Priority Queue + Aging Counter

Interrupts running jobs if a higher-priority task arrives. Integrates an aging mechanism to eliminate starvation.

📘 About This Engineering Project

Full Documentation

This project was built to illustrate the vital symbiosis between Data Structures and Operating Systems. In textbook algorithms, process selection is often treated as an abstract mathematical decision; this interactive visualizer exposes the practical pointer manipulations, contiguous memory offsets, and comparison counts executed under the hood.
