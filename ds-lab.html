Module C: Circular Queue (Ring Buffer)

Modulo: (rear + 1) % size

In standard linear queues, dequeuing elements leaves unutilized memory at the front. The Circular Queue solves this by wrapping the rear pointer back to 0 using modulo arithmetic: rear = (rear + 1) % capacity. This is the exact data structure used by Round Robin time-sharing schedulers.

Module D: Binary Min-Heap (SRTF & Priority Queue)

O(log N) Priority Access

Min-Heaps guarantee that the minimum remaining burst time (in SRTF) or highest priority job (in Priority Scheduling) sits at the root (index 0). Insertion runs in O(log N) via bubble-up, and Extract-Min runs in O(log N) via heapify-down.
